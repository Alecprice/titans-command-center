# Titans Command Center — Brand/UI direction

## Current identity (2026)

Source of truth: Tennessee Titans official brand pages.

- Primary logo: **The Shield** (circular T + three stars).
- Dominant color: **Titans Blue**.
- Supporting colors: white, navy, red, with silver/gray where dimensional treatment is needed.
- Official brand presentation uses Titans Blue as the largest color proportion, then white, with navy and red as accents.
- Official brand type system identifies **Archivo** plus custom Titanblock condensed/extended display faces.
- Main UI uses Archivo where available and safe system fallbacks; it does not redistribute proprietary/custom team font files.
- The six-stripe visual motif is used as a web-native reference to the 2026 “6-String Stripe.”

Web palette used in the fan UI:

- Titans Blue: `#4B92DB`
- Navy: `#0C2340`
- Red: `#C8102E`
- White: `#FFFFFF`
- Silver: `#8A8D8F`

These HEX values are practical digital values consistent with the visual identity; the publicly accessible team brand page does not publish a full HEX/Pantone table in text.

## Legacy / throwback treatment

The Legacy area intentionally changes tone so it feels like a franchise archive rather than another dashboard page.

- Oilers / powder blue: `#4A95CE`
- Throwback red: `#D5272C`
- Old navy: `#002144`
- Warm archive cream: `#F7F3EA`

Era structure:

1. 1960–1996 — Houston Oilers
2. 1997–1998 — Tennessee Oilers
3. 1999–2025 — Titans fireball era
4. 2026–present — The Shield era

## UX rules

- Do not use one generic rounded card style everywhere.
- Current-brand pages use sharp/chamfered athletic geometry, blue fields, white information surfaces, and red impact accents.
- Legacy sections use cream/powder-blue archival surfaces and supplied throwback imagery.
- Mobile bottom navigation prioritizes Home, Game Day, Roster, Stats, Intel, and Legacy.
- Team marks are used for an unofficial fan experience and are not presented as ownership or official affiliation.
